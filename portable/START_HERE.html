Reproduce the paper results

  1. Extract PISCO-linux-x86_64.zip.
  2. Open PISCO inside the extracted folder.
  3. Choose an output folder and select Check paper results.

Saved data and dependencies are included. You do not need Docker, an installed Python or an internet connection during use.

Check paper results verifies saved data and statistics.

Run short test calculates small examples.

Start complete run calculates the full experiment matrix and can take days.

Resume complete run continues a calculation with the same environment and worker count.

Progress and errors appear in the window. Use Stop to stop safely; completed results and logs remain in your output folder.

Linux x86-64, glibc 2.36 or later, X11/XWayland desktop. See validation and instructions for tested conditions. Other systems and cross-platform numerical equality are not established.
