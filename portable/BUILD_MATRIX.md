# Tested platforms

| Platform | Status |
| --- | --- |
| Linux x86-64 | Locally tested on the recorded AMD laptop and isolated Debian 12 userland; see VALIDATION.md |
| Windows, macOS and other platforms | No validated application release |

The isolated userland shares the laptop's CPU and kernel. It is not an independent
hardware test. No universal compatibility or cross-architecture bitwise numerical
equality is claimed. Further platforms require their own builds and acceptance.
